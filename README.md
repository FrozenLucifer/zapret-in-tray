# ZapretTray

Простой клиент и трей-меню для  
**zapret-discord-youtube** от Flowseal  
(https://github.com/Flowseal/zapret-discord-youtube)

## Описание
При первом запуске скачивается содержимое официального репозитория **zapret-discord-youtube**.
Проверка обновлений сверяет версию с официальным репозиторием и, если есть новая, открывает её страницу релиза по подтверждению пользователя. Это не перезаписывает пользовательские списки и настройки незаметно.

На данный момент реализованы не все функции.
Дополнительную настройку можно выполнить через `service.bat`, открыв его из трея.

## Реализованные функции
- Запуск `.bat` файлов
- Установка сервисов
- Удаление сервисов
- Проверка обновлений Zapret
- Управление автозапуском приложения
- Очистка кеша Discord (с предупреждением о закрытии Discord)
